# Birim

Bu menüde birimin personel listesi ve birime ait dokümanlar yönetilir.

## Bu sayfayı kimler kullanır

| Rol | Yapacağı işler |
|-----|----------------|
| Rapor Yetkilisi | [Personel listesini düzenleme](#personel-listesi), [Birim dokümanlarını yönetme](#birim-dokumanlari) |
| Birim personeli (Rapor Yetkilisi'nin personel listesine eklediği kullanıcılar) | [Birim dokümanlarını görüntüleme](#birim-dokumanlarini-goruntuleme) |

## Personel listesini düzenleme {#personel-listesi}

!!! note "Rol"
    Rapor Yetkilisi

1. **Birim** > **Birimim** menüsüne girin.
2. Birden fazla biriminiz varsa açılır listeden birimi seçin.
3. **Personel Listesi** panelinde **Düzenle** butonuna tıklayın.
4. **Personeli Düzenle** ekranında **Personel** alanından kullanıcıları seçin.
5. **Kaydet** butonuna tıklayın.

## Birim dokümanlarını yönetme {#birim-dokumanlari}

!!! note "Rol"
    Rapor Yetkilisi

### Kategori oluşturma

1. **Birim** > **Birim Dokümanları** menüsüne girin.
2. **Birim Kategorisi Oluştur** butonuna tıklayın.
3. **Kategori** alanını doldurun ve **Birim**i seçin.
4. Kategorinin birim personeline görünmesi için **Görünsün mü?** kutusunu işaretleyin.
5. **Oluştur** butonuna tıklayın.

### Doküman ekleme

1. **Birim** > **Birim Dokümanları** menüsünde kategorinin adına tıklayın.
2. **Dokümanlar** panelinde **Doküman Oluştur** butonuna tıklayın.
3. **Doküman** alanını doldurun. Doküman bir bağlantıysa **Url** alanını doldurun.
4. **Oluştur** butonuna tıklayın.
5. Dosya eklemek için dokümanın satırındaki **Dosyalar** butonuna tıklayın ve **Dosya Ekle** butonunu kullanın.

## Birim dokümanlarını görüntüleme {#birim-dokumanlarini-goruntuleme}

!!! note "Rol"
    Birim personeli

1. **Birim** > **Birim Dokümanları** menüsüne girin.
2. Kategorinin adına tıklayın; dokümanlar **Dokümanlar** panelinde listelenir.
